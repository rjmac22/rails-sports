# Rails Sports House Style

This is a lightweight, evolving house-style guide for Rails Sports.

## Principle

Do not invent rules in advance. Add a house-style rule only when a recurring editorial choice actually arises in production.

For each recurring choice:

1. Ask whether it is genuinely recurring rather than a one-off sentence-level edit.
2. Ask whether Rails Sports has a reader, clarity, tone, sport-specific, or presentation reason to prefer one form.
3. If there is no Rails Sports-specific reason, use a consistent British-journalism default.
4. Record the decision once here.
5. Apply it consistently in later articles and run a house-style consistency pass before publication.

Do not rewrite clear copy merely because an editor would have phrased it differently. Changes to finished prose need a specific editorial reason.
