# Rails Sports House Style

This is a lightweight, evolving house-style guide for Rails Sports.

## Principle

The first published Rails Sports piece is the baseline for house style. New articles should be consistent with conventions already established there unless there is a specific reason to change them.

Do not invent rules in advance. Add a house-style rule only when a recurring editorial choice actually arises in production.

For each recurring choice:

1. Check how the first published piece and any later published Rails Sports pieces handled it.
2. Ask whether the choice is genuinely recurring rather than a one-off sentence-level edit.
3. If the existing treatment is clear and sensible, keep it.
4. If the existing treatment is inconsistent or there is a strong reader, clarity, tone, sport-specific, or presentation reason to change it, decide the new rule deliberately and apply it consistently going forward. Where practical, bring earlier pieces into line too.
5. If there is no Rails Sports-specific precedent or reason, use a consistent British-journalism default.
6. Record the decision once here.
7. Run a house-style consistency pass before publication.

Do not rewrite clear copy merely because an editor would have phrased it differently. Changes to finished prose need a specific editorial reason.
